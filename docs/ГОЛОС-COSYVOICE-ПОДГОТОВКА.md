# Подготовка голоса CosyVoice 3

Дата: 20 сентября 2026

## Состояние

- В `voice_reference/suit_male` обнаружено 715 игровых реплик `.mp2`.
- Исходные файлы: стерео, 44.1 кГц, английская речь.
- Подготовлен набор `artifacts/cosyvoice-dataset/wav`: моно, 24 кГц, PCM WAV.
- Созданы `manifest.json` и `manifest.csv`.
- В каждой записи поле `text` пока пустое и имеет статус `needs_transcript`.

## Почему обучение пока не запускается

CosyVoice обучается на парах `audio + transcript`. Имена файлов недостаточны для точной разметки: часть имён описывает игровые события, а не дословный текст реплики. Обучение без транскрипций приведёт к плохому выравниванию и не даст качественный русский голос.

Следующий корректный этап: заполнить `artifacts/cosyvoice-dataset/manifest.csv` точными английскими транскрипциями, затем подготовить train/dev split и parquet/list формат по требованиям `CosyVoice3/cosyvoice/dataset`. После этого можно запускать сначала короткий sanity-run, а не полное обучение.

## Инструмент подготовки

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/prepare-cosyvoice-dataset.ps1
```

Скрипт идемпотентен, исходные `.mp2` не изменяет и не скачивает ничего из сети.
