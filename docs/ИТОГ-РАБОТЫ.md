# TOLIK — итог текущей работы

Дата: 19 сентября 2026 года

## Что реализовано

- Модульное решение .NET 10 / C# 14 с разделением Core, Agent, Contracts и Infrastructure.
- PostgreSQL с EF Core, миграциями, readiness-проверкой, backup/restore и безопасностью восстановления.
- Версионируемые Core-Agent contracts с детерминированной проверкой malformed JSON.
- Защита секретов в логах и сканирование утечек.
- Core API и CLI со статусом, correlation ID и fail-closed authentication boundary.
- Owner/device/session lifecycle: bootstrap, P-256 challenge, подпись, replay protection, revoke и expiry.
- Authorization policy с уровнями риска, confirmation и MFA для critical операций.
- Append-only audit с redaction и hash chain.
- Authenticated Agent connect и capability validation.
- Persistent task lifecycle: создание, cancellation, PostgreSQL persistence и чтение вторым Core process.
- Allowlisted filesystem tools с canonical path isolation и sensitive-path denylist.
- Configurable model router, provider adapters, timeout/cancellation и fake-provider failure tests.
- Отдельные Codex/OpenCode runners с process capture, timeout и cancellation.
- Bounded planner, prompt-injection filtering и execution guard.
- Scoped memory, people, personality/humor foundation и API endpoints.

## Проверки

- Текущее решение собирается без предупреждений и ошибок.
- Полный набор автоматических тестов проходит.
- Реальные Docker/PostgreSQL/HTTP harness сценарии проверяли identity, audit, tasks, Agent connect, revoke и filesystem allow/deny.
- Provider API calls не выполнялись без отдельного connectivity probe; секреты не записываются в evidence.

## Что осталось

- Довести durable memory/personality persistence и multi-user live QA.
- Thin Linux/Android clients.
- Voice, perception, proactive learning и home/VPS deployment.
- Финальный F1-F4 acceptance и security gate.
