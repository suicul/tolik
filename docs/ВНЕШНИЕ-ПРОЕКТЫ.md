# Внешние проекты — что взять, а что не брать

Разбор чужих решений на предмет переноса в TOLIK. Правило: сначала понять,
**какую проблему решает чужой механизм**, потом проверить, есть ли эта проблема
у нас, и только потом переносить. Копировать целиком чужую архитектуру нельзя —
TOLIK строится вокруг своих границ (AGENTS.md §2, §44, §45).

Обновлено 05.11.2026.

---

## app_ai_assistant (Mike2024New) — релиз 1.0.0

Локальный голосовой ассистент на Python: микрофон → Vosk/Whisper → llama.cpp
(Gemma 3) → Silero TTS. Микросервисы по WebSocket/HTTP, GUI на CustomTkinter.

Лицензии: сам проект MIT; Vosk — Apache 2.0; Silero — **CC BY-NC-SA 4.0**;
модели Gemma — Gemma Terms of Use.

### Что у них решено хорошо

**1. Настоящее прерывание (barge-in).** Ключевой механизм —
`pipeline/main.py`, `observer_callback`:

```python
async def observer_callback(self):
    if self._llm is not None:
        self._llm.interrupt()
    if self._llm_task is not None and not self._llm_task.done():
        self._llm_task.cancel()
        await asyncio.gather(self._llm_task, return_exceptions=True)
    if self._tts is not None:
        await self._tts.interrupt()
```

STT работает постоянно и на появление новой речи дёргает этот callback:
генерация отменяется, озвучка обрывается на полуслове. Плюс на пути
`_stt_callback` есть guard `_stop_assistant_wait`, чтобы собственный голос
ассистента не принимался за команду.

**2. Постоянное слушание вместо кнопки.** STT запущен всё время
(`self._stt.listen(callback=...)`), а не по нажатию. Отсюда мгновенная реакция:
не нужно нажимать кнопку и не нужно дожидаться конца записи.

**3. Секретарь сессии.** На остановке LLM сам делает суммаризацию истории и
пишет её в JSON; на старте история подгружается — примитивная, но работающая
память между запусками.

**4. Маршрутизация команд.** Сначала проверка первого слова на имя ассистента,
затем точное совпадение по словарю, и только потом LLM-классификация с жёстким
промптом «верни только номер команды или -1». То есть модель не получает права
выполнять — она только сопоставляет.

### Что у TOLIK есть, а что нет

Проверено по коду 05.11.2026:

| Механизм | TOLIK | Разрыв |
|---|---|---|
| Поточная озвучка | **есть**: `VoiceTurnClient` отдаёт аудио по мере поступления, воспроизведение начинается до конца хода (`VoiceTurnClient.cs:77`) | — |
| Прерывание | **только по кнопке**: `ChatWindow.xaml.cs:169` — `StopPlayback()` вызывается в `ToggleMicrophone()` | Прерывания голосом нет |
| Постоянное слушание | **нет**: `MicrophoneRecorder.Start()` → `Stop()` собирает весь ход целиком | Нет партиалов, нет VAD |
| Память между запусками | **есть**, и сильнее их: PostgreSQL, приватность, атрибуция | — |

### Что переносим

**З1. Прерывание по голосу (barge-in).** Приоритет высокий: это прямая жалоба
владельца (сессия idx=1723 — «он так же не прерывается когда я говорю»).
Нужно: VAD-контур, который слушает во время воспроизведения, и на подтверждённую
речь вызывает остановку воспроизведения и отмену текущего хода. Затрагивает
`src/TOLIK.Desktop/Voice/MicrophoneRecorder.cs`, `ChatWindow.xaml.cs`.
Входит в Фазу 4, задача 4.3.

**З2. Партиалы STT для мгновенного старта.** Приоритет высокий: вторая прямая
жалоба — «команды распознавания речи доходят прям долго, более минуты».
Сейчас весь ход пишется целиком, потом распознаётся. Их схема — быстрый движок
даёт черновой текст сразу, точный уточняет — убирает основную задержку.
Входит в Фазу 4, задача 4.3.

**З3. Guard против собственного голоса.** Мелочь, но нужна вместе с З1:
пока TOLIK говорит, его собственная озвучка не должна попадать в микрофон и
запускать прерывание. У них — флаг `_stop_assistant_wait`; у нас понадобится
эквивалент с учётом того, что выход идёт через динамики.

### Что НЕ переносим

- **Локальную LLM (Gemma через llama.cpp).** Прямо противоречит решению
  владельца: облако через `tooken`, локальная модель только аварийная и без
  постоянной нагрузки на GPU (память проекта, 02.11.2026).
- **Silero TTS и её модели.** Лицензия **CC BY-NC-SA 4.0** — некоммерческая.
  Использовать в личном проекте можно, но это ограничение, заложенное в
  архитектуру; TOLIK намеренно держит TTS заменяемым (`edge-tts` по умолчанию,
  XTTS по кнопке, финальная цель — свой голос).
- **GUI на CustomTkinter.** TOLIK — WPF, и владелец прямо сказал: Windows-клиент
  главный.
- **Микросервисную схему из трёх сервисов.** У TOLIK уже есть разделение
  Core / Agent / Voice, и оно своё; дублировать чужую топологию незачем.

### Лицензионная заметка

Код самого проекта — MIT, адаптировать можно. Но перед переносом любого
фрагмента следует проверить, не пришёл ли он из компонента с другой лицензией.
Особенно это касается всего, что связано с Silero.

## Как пользоваться этим файлом

Раздел с чужим проектом нужен не для коллекционирования ссылок, а чтобы
задачи Фазы 4 опирались на проверенный опыт, а не на догадки. Если механизм
перенесён — сюда добавляется строка с коммитом, чтобы было видно, что именно
и когда взяли.
